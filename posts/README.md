# Blog posts

All locally hosted posts live here, grouped by category:

- `neurons-and-numbers/`: neuroscience and computation.
- `perspective/`: business, society, and global challenges.
- `life/`: future locally hosted travel, hiking, and photography posts. The current Life link still points to the external blog.

Use a descriptive filename such as `neurons-and-numbers/depression-neurogenesis.html`.
From a post, use `../../` for shared styles, scripts, and top-level navigation pages.
Add each new post's title link and brief overview to its category listing at the site root.
The root `depression-neurogenesis.html` is a redirect for existing links; edit the article inside this folder.
